# Steam Controller PC

Free tool to use a Steam Controller outside Steam - maps the trackpads, grips and sticks to keys and mouse. Windows 10/11, portable.

**[⬇ Download for Windows](https://github.com/jasminritik26/steam-controller-pc/releases/latest)** · [Website](https://steamcontrollerpc.com)

## What it does

Without Steam running, the pad is mostly dead on Windows - the trackpads do nothing and the grips do not exist. This tool talks to the controller directly and turns every input into a real keystroke, mouse click or mouse movement, so it works in emulators, browser games, launchers and any application that never heard of Steam.

## Features

- Works without Steam running, in any application
- Maps buttons, triggers, stick, both trackpads and the back grips
- Right trackpad drives the mouse, adjustable sensitivity and deadzone
- Left trackpad can act as a D-pad
- Bind any input to a key, a mouse click or mouse movement
- Named profiles, one per game, swapped in a click
- Global hotkey turns mapping off without unplugging
- No drivers, portable, free and open source (MIT)

## Install

1. Download the latest release: **[Steam Controller PC](https://github.com/jasminritik26/steam-controller-pc/releases/latest)**
2. Run the installer. No admin rights, no extra components.
3. Start it from the Start menu.

Windows 10 and Windows 11, 64-bit. Nothing else is required.
